This repository is a native Android application written in Kotlin with Jetpack Compose. Android apps run on a phone or an Android emulator — there is no web frontend to preview here. This page exists so the Replit preview pane has something to display.

Environment ready

What's configured in this Replit

  • Java toolchain (GraalVM 19 / OpenJDK) — used by Gradle
  • Project files and the Gradle wrapper (./gradlew)
  • This status page served on port 5000

The Android SDK is not installed in this Replit container — the SDK is ~10 GB and is intended for a desktop development setup. To produce an installable APK, build the project locally in Android Studio (recommended) or on a CI runner with the Android SDK available.

Build & run on your machine

  1. Install Android Studio Hedgehog (or newer) with Android SDK 34.
  2. Open this folder in Android Studio — Gradle sync runs automatically.
  3. (Optional) For the cloud OCR fallback, add OPENAI_API_KEY=sk-... to local.properties.
  4. Connect a device or start an emulator and press Run.

From the command line (with Android SDK installed and ANDROID_HOME set):

./gradlew assembleDebug
# APK output: app/build/outputs/apk/debug/app-debug.apk

What the app does

  • Add, edit, and delete products with manufacturing & expiry dates
  • Capture a label with the camera or pick from the gallery
  • On-device OCR with Google ML Kit, with an optional cloud LLM fallback
  • Auto-fills the form with extracted product name and dates
  • Local persistence via Room (SQLite)
  • Material 3 + Jetpack Compose, Android 7.0+ (minSdk 24, target 34)
