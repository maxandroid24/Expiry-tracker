API

The Android app talks to this single endpoint:

POST /ocr

Request body

{
  "image": "<base64-encoded JPEG bytes, <= 8 MB>",
  "hint":  "<optional ML Kit OCR text>"
}

Successful response

{
  "name":       "Whole Wheat Bread",
  "mfgDate":    "2025-01-12",
  "expDate":    "2025-02-08",
  "confidence": 0.92
}

Dates are ISO format: YYYY-MM-DD when the day is printed, YYYY-MM when only month/year are visible. Any field can be null. The endpoint is rate limited to 20 requests per minute per IP.

Security

Why an OCR backend?

  • The OpenAI API key lives only on the backend (Replit Secrets / env var).
  • The Android app contains no hardcoded secrets and no BuildConfig API key.
  • The app only knows the URL of this backend — set via BACKEND_OCR_URL in local.properties.
  • Body size is capped, base64 input is validated, and rate limiting is enforced per IP.
